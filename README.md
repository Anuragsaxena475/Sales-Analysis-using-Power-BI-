 📊 Power BI Interactive Sales Dashboard | Kaggle Dataset

This project showcases an interactive Power BI dashboard built using a sales dataset from Kaggle. The dashboard provides deep insights into sales performance, profit trends, shipping analysis, and regional distribution — all visualized through dynamic Power BI reports.

---

 📁 Dataset Overview

Source: [Kaggle Sales Dataset](https://www.kaggle.com/) *(Insert actual link if available)*
- Columns Included:

| Feature           | Description                                 |
|-------------------|---------------------------------------------|
| Order ID          | Unique identifier for each order            |
| Order Date        | Date when the order was placed              |
| Ship Date         | Date when the order was shipped             |
| Month, Year       | Extracted time features for analysis        |
| Ship Mode         | Shipping method used                        |
| Customer ID       | Unique ID for each customer                 |
| Customer Name     | Full name of the customer                   |
| Segment           | Customer segment (e.g., Consumer, Corporate)|
| Country, City, State | Location details                        |
| Postal Code       | Postal code of the delivery address         |
| Region            | Region-wise classification (e.g., East)     |
| Product ID        | Unique identifier for the product           |
| Category          | Product category (e.g., Furniture)          |
| Sub-Category      | Detailed product type (e.g., Chairs)        |
| Product Name      | Full name of the product                    |
| Sales             | Revenue from the sale                       |
| Quantity          | Number of items sold                        |
| Discount          | Discount applied                            |
| Profit            | Profit earned from the transaction          |
| Profit Loss       | Profitability status (Profit or Loss)       |

## 🎯 Objectives

- Clean and prepare sales data using Power Query
- Create key metrics and measures using DAX
- Visualize insights for:
  - 📈 **Sales & Profit Trends Over Time**
  - 🛒 **Top Products, Categories & Segments**
  - 🌍 **Geographical Performance by Region/State**
  - 🚚 **Shipping Mode & Delivery Analysis**
  - 👥 **Customer and Segment Breakdown**

---

## 🛠 Tools & Technologies

- **Power BI Desktop**
- **Power Query**
- **DAX (Data Analysis Expressions)**
- **Kaggle Dataset (CSV format)**

## 🚀 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/powerbi-sales-dashboard.git
   ```
2. Open the `.pbix` file in Power BI Desktop
3. Ensure your dataset path is correctly mapped (Power Query Editor)
4. Interact with slicers, filters, and visuals to explore insights
